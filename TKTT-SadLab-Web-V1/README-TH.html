TKTT SadLab Web V1 — ไลฟ์จากมือถือ ไม่ต้องลงแอป

หน้าเว็บหน้าเดียว แสดงห้อง DJ (ภาพหรือวิดีโอ) และแท่น DJ ที่มีชื่อช่องกับ EQ ไม่แสดงชื่อเพลง ไม่ต้องใช้คอมหรือ Termux ค่าที่ตั้งไว้เก็บในเบราว์เซอร์ของมือถือเครื่องนั้น

1. เอาขึ้นเว็บ (ทำครั้งเดียว)

  1. สร้าง repository ใหม่ใน GitHub เช่น tktt-live
  2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ index.html อยู่ชั้นบนสุดของ repository
  3. Settings › Pages › Branch: main / root › Save แล้วรอ 1–2 นาที
  4. จะได้ลิงก์ https://<ชื่อผู้ใช้>.github.io/tktt-live/ (ต้องเป็น https ไม่อย่างนั้นโหมดไมโครโฟนจะใช้ไม่ได้)

2. ใช้งานบนมือถือ

  1. เปิดลิงก์ใน Chrome → เมนู ⋮ → เพิ่มลงในหน้าจอหลัก ครั้งต่อไปเปิดจากไอคอน "TKTT LIVE" ได้เลย
  2. กด ⚙ ตั้งค่า เลือกห้อง EQ ข้อความบนแท่น และตั้งเปลี่ยนห้องอัตโนมัติ แล้วกดปิดตั้งค่า
  3. แตะ "แตะเพื่อเริ่ม" ระบบจะเปิดเต็มจอ ไม่ให้หน้าจอดับ และเริ่ม EQ
  4. เปิดเพลงใน YouTube Music ถ้าต้องการ ส่วนนี้ไม่ต้องเชื่อมกับเว็บ
  5. เปิดโหมดห้ามรบกวน แล้วเปิด TikTok › LIVE › การเล่นเกมมือถือ › เริ่ม LIVE จากนั้นสลับกลับมาที่ TKTT LIVE
  6. ระหว่างไลฟ์ ถ้าต้องการเปิดตั้งค่า ให้กดค้างที่หน้าจอ 1.5 วินาที แต่ผู้ชมจะเห็นหน้าตั้งค่าด้วย

3. ข้อจำกัด

  • EQ "จำลองจังหวะ" ไม่ได้ขยับตามเพลงจริง ส่วน "ไมโครโฟน" ฟังเสียงจากลำโพงมือถือ และอาจแย่งไมค์กับ TikTok ให้ทดสอบก่อนไลฟ์จริง
  • เสียงเพลงจะเข้าไลฟ์ในโหมดแชร์หน้าจอหรือไม่ ขึ้นกับแอปเพลงและรุ่น Android ให้ไลฟ์ทดสอบสั้น ๆ ก่อน
  • ถ้าวิดีโอพื้นหลังกระตุกหรือมือถือร้อน ให้ปิด "เล่นวิดีโอพื้นหลัง" ในหน้าตั้งค่า
  • เพิ่มห้องใหม่: วางไฟล์ใน assets/rooms/ แล้วเพิ่มชื่อไฟล์ใน shared/core-local.js ที่ส่วน FIXED
  • ทดสอบแล้วในเบราว์เซอร์ที่ตั้งขนาดจอมือถือ แต่ยังไม่ได้ทดสอบบน Android จริงกับ TikTok
